How to read this page Evidence ≠ a green command

01 · Exercise behavior

The packaged engine uses shipped CLI operations. Desktop checks add real Qt controls and an instrumented local app. Service checks exercise background operations. These are different kinds of coverage.

02 · Assert an outcome

Read back identities, timing, saved state or actual media output. A successful dispatch is insufficient. Each detail panel explains the expected outcome and how the check verifies it.

03 · Keep the limits visible

Pass describes a retained run. Blocked means the requirement was not established. One script may cover only part of Logan’s original path. Newer attempts can be affected by the harness or environment.

The reference column combines selected historical records; it is not a release pass rate. Technical evidence and source code are available through “Troubleshoot this check.”
