QtQuick Agent Workspace composer. The managed MBP remains on the October 11
deployment until this source is reviewed and qualified.

## Investigation

- Reports and agent packets retain bounded input and wait diagnostics, including
  covering-window identity, geometry and recorded dispatch state. They omit
  window titles and unrelated UI content.
- Missing-media checks record setup, available-source capture, removal and
  recovery phases. A failed timeline setup leaves the media-loss behavior
  explicitly unreached.
- Bin duplication, native window ordering, header layout and inline-image sizing
  retain expected/observed comparisons through the existing independent oracles.
- Graphic publication Undo/Redo records each dispatch, history movement, restored
  placement and rendered-pixel comparison separately. Animated-tail history also
  records each Undo/Redo movement. A no-op stops the dependent checks and keeps
  the actual history response for investigation.
- Cleanup no longer appears as the last completed test action. Unknown input
  retains its reconciliation requirement.
- Ambiguous media names are rejected before focus or menu input. Timing blockers
  expose source identity, range, clock and projection diagnostics without
  weakening the exact-timing requirement.

## Agent Workspace controls

Adapter version 13 adds composer inspection, text insertion and Send dispatch.
Requests bind the observed editor, Send control and QtQuick surface to the owned
process generation and exact current draft. Insertion preserves existing text
and the observed caret, rejects occupied selections, and checks readback. A fresh
QtQuick hit check rejects covered controls. The adapter does not touch the clipboard.

Send performs one Qt pointer click. A dispatch receipt remains separate from
provider progress and results. Stale, replaced, hidden, disabled or changed
targets reject input; uncertain readback stops further edits.
