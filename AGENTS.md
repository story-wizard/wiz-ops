# Agent entry points

For Athanor smoke testing, read [smoke/AGENTS.md](smoke/AGENTS.md), then work from `smoke/`. The dashboard, course runner and agent CLI all use the same local service. Start with the source-launch instructions there; review/build automation elsewhere in this repository is separate work.

Keep test projects, builds, models, plans, captures and reports outside Git. Preserve recorded outcomes and identify the selected build in every test report.
